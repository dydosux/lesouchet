# 🌲 ЛесоУчёт — Мобильное приложение распиловки древесины и расчёта зарплаты

Автономное приложение для смартфонов (Android / iOS) и ПК для автоматического распознавания рукописных ведомостей распиловки, кубатурника **ГОСТ 2708-75** и автоматического расчёта зарплаты бригады без платных токенов и API.

---

## 🚀 Как закинуть этот проект на свой GitHub за 3 шага

1. Создайте новый пустой репозиторий на [github.com/new](https://github.com/new) (например, с именем `lesouchet`).
2. В этой папке откройте терминал (PowerShell / Командная строка) и выполните:
   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГИН_GITHUB/lesouchet.git
   git branch -M main
   git push -u origin main
   ```
3. После отправки на GitHub, встроенный робот **GitHub Actions** автоматически скомпилирует готовый файл **`app-debug.apk`** и выложит его во вкладку **Releases** (Релизы).

## 📱 Как установить приложение на телефон

### Вариант 1: Прямо через браузер смартфона (PWA — без скачивания файлов)
1. Откройте приложение в браузере телефона (**Google Chrome**, **Яндекс.Браузер** или **Safari**).
2. Нажмите на меню браузера (три точки **⋮** в правом верхнем углу на Android или кнопку «Поделиться» на iPhone).
3. Нажмите **«Установить приложение»** (или «Добавить на главный экран»).
4. Иконка **«ЛесоУчёт»** появится на рабочем столе смартфона и будет работать автономно на весь экран.

### Вариант 2: Установка готового APK
1. Зайдите с телефона на страницу вашего репозитория на GitHub в раздел **Releases**.
2. Скачайте файл **`app-debug.apk`**.
3. Нажмите на файл и выберите «Установить».

## 🧮 Формулы и логика расчёта зарплаты (по ТЗ)

1. **Круглый лес (Сырьё):**
   * Ввод списка диаметров брёвен (в вершине, см) для стандартной длины 6.0 м.
   * Кубатура вычисляется по официальному стандарту **ГОСТ 2708-75**.
   * *Пример:* 14 брёвен = **4.887 м³ сырья**.

2. **Готовая продукция (Пиломатериал):**
   * Кубатура досок 1-го и 2-го сорта, бруса:
     $$V = \frac{\text{Толщина (мм)} \times \text{Ширина (мм)} \times \text{Длина (м)}}{1\,000\,000} \times \text{Количество (шт)}$$
   * *Пример:* **4.192 м³ готового пиломатериала**.

3. **Коэффициент выхода леса:**
   * Формула: $\frac{\text{Кубатура готового}}{\text{Кубатура кругляка}} \times 100$.
   * **Всегда округляется в меньшую сторону** (функция `Math.floor`):
     $$\frac{4.192}{4.887} \times 100 = 85.7\% \longrightarrow \mathbf{85\%}$$

4. **Расчёт зарплаты бригады:**
   * Готовая продукция: $\text{Кубатура (м³)} \times 1600 \text{ руб.} = 4.192 \times 1600 = \mathbf{6707 \text{ руб.}}$
   * Горбыль 2м (штакет, необрезная доска): $\text{Количество (шт)} \times 25 \text{ руб.} = 48 \times 25 = \mathbf{1200 \text{ руб.}}$
   * **Итого к выдаче бригаде:** $6707 + 1200 = \mathbf{7907 \text{ руб.}}$

## 💻 Локальный запуск на компьютере

### Запуск веб-интерфейса:
```bash
npm install
npm run dev
```
Открыть в браузере: `http://localhost:3000`

### Запуск сервера оптического распознавания (FastAPI OCR):
```bash
cd backend
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```
