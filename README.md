# ЛесоУчёт v1.1 — реальное OCR бланков распиловки + расчёт зарплаты

Автономное Android/PWA-приложение: настоящее распознавание фото бланка (Tesseract.js rus+eng), кубатурник ГОСТ 2708-75 и расчёт зарплаты бригады без платных токенов.

## Скачать APK

Откройте: https://github.com/dydosux/lesouchet/releases

Скачайте `LesoUchet-v1.1.0.apk` и установите на телефон.

При первом OCR нужен интернет (скачиваются языковые модели ~15 МБ). Дальше работает офлайн.

## Что реально работает

1. Камера / галерея → предобработка фото → Tesseract OCR
2. Парсинг размеров (30X100X6 и т.д.), 1/2 сорта, бруса, горбыля, кругляка
3. Кубатура пиломатериала и брёвен (ГОСТ 2708-75, 6 м)
4. Выход леса % с округлением вниз
5. Зарплата: куб × 1600 + горбыль × 25
6. Ручная правка любой цифры + Excel/CSV экспорт

## Локальный запуск

```bash
npm install
npm run dev
```

Опциональный Python OCR-бэкенд:

```bash
cd backend
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```

В APK/PWA используется встроенный Tesseract.js, сервер не обязателен.
